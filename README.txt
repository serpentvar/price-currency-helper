1. 在 serpentvar 帳號建立 Public 儲存庫，命名 price-currency-helper。
2. 上傳 index.html 至儲存庫根目錄並提交。請上傳解壓縮後的 HTML，不是 ZIP。
3. Settings → Pages → Deploy from a branch → main → /(root) → Save。
4. 等待 GitHub 顯示網站發布成功，再開啟並確認公開網址。
