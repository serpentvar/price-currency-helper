適用範圍與聯絡方式

本政策適用於「網頁換匯小幫手 / Price Currency Helper」Chrome 擴充功能 v3.0.2–v3.0.4。發布者：Cassidy Chen。隱私聯絡信箱：cassidyvar@gmail.com。生效日期：2026-11-05。

頁面內容如何使用

擴充功能會在啟用的普通 HTTP / HTTPS 網頁中讀取頁面文字，以辨識外幣標價並在旁邊插入估算金額。這些文字可能包含頁面上的其他內容，但僅在本機用於價格辨識，不會由擴充功能傳送給發布者或匯率服務。它不會建立完整瀏覽紀錄，不會讀取 Cookie、輸入欄位中的帳密或付款資料，也不會替你下單或付款。

本機保存的資料

使用 chrome.storage.local 保存目標幣別、介面語言、全域與網站開關、費用百分比、手動匯率、網站幣別設定，以及匯率表、來源日期、更新與重試時間和錯誤狀態。網站設定以你儲存設定時的網站網域為索引。開啟設定面板時，擴充功能透過 activeTab 讀取當前分頁網址並擷取網域，以顯示及保存本站設定；不保存完整網址或商品清單。這些資料不透過本擴充功能同步至開發者伺服器，也不使用 chrome.storage.sync。

匯率服務與外部連線

在頁面或設定面板請求狀態時，擴充功能可能經由 HTTPS 連線至 https://open.er-api.com/v6/latest/USD 取得 USD 基準的匯率表，並在本機交叉換算。通常沿用約 24 小時內的快取；使用者可手動要求更新，失敗重試另有節流。v3.0.4 讀取設定只在本機進行；全域或本站停用時，不會由該頁觸發新的自動匯率請求。頁面辨識到的所有幣別均有有效手動匯率，或沒有需要換算的價格時，也不會為該頁自動取得匯率。有未設定手動匯率的其他幣別仍需換算時，可能取得自動匯率表。使用者在設定面板主動按「更新匯率」是例外；停用前已送出的請求不會追溯取消。舊版 v3.0.2／v3.0.3 讀取狀態時，即使用手動匯率或關閉顯示，也可能檢查匯率。請求不附帶商品、價格、頁面文字、瀏覽網址、網站設定或使用者帳密。匯率服務及其網路基礎設施仍可收到 IP 位址、請求時間及一般連線資訊；其處理由服務方的政策決定。本擴充功能不控制該服務的日誌或保存期限。服務條款與隱私內容：https://www.exchangerate-api.com/terms 。

資料分享、廣告與追蹤

發布者沒有用來收集頁面內容、使用紀錄或個人資料的後端伺服器。本版本沒有廣告 SDK、分析追蹤、遙測或擴充功能帳號系統；不會販售頁面資料，也不會將本機資料用於廣告、信用評估或與換匯無關的用途。點擊匯率來源等外部連結時，會直接前往該網站，其資料處理由該網站政策規範。

權限用途

storage：保存本機偏好與匯率快取。activeTab：在你開啟設定時取得目前網站的網域。HTTP / HTTPS 頁面內容存取：在不同網站辨識價格並顯示估值；你可利用工具的單站開關，或 Chrome 的網站存取控制限制它。open.er-api.com 主機存取：透過 HTTPS 取得匯率 JSON 資料。遠端回應僅作匯率資料使用，不作遠端程式碼執行。

保存、控制與刪除

本機設定與匯率快取會保存到被更新、清除或移除擴充功能為止；使用期間沒有固定的自動刪除期限。你可修改設定、清除特定手動匯率、關閉網站換算或移除擴充功能。移除通常會清除 Chrome 管理的該擴充功能本機儲存；你自行建立的瀏覽器或系統備份需自行處理。發布者無法遠端查看或刪除這些本機設定，也無法替你刪除匯率服務方的連線日誌。

資料使用限制與政策更新

本擴充功能對使用者資料的使用遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求，限於提供與維護已揭露的價格換算功能。若未來改變資料處理方式，本政策會更新並標示生效日期；重大變更將按適用商店政策揭露。隱私問題請聯絡上述公開信箱。

Privacy Policy

Scope and contact

This policy applies to the Chrome extension “網頁換匯小幫手 / Price Currency Helper”, versions 3.0.2–3.0.4. Publisher: Cassidy Chen. Privacy contact: cassidyvar@gmail.com. Effective date: 2026-11-05.

Page content

On enabled ordinary HTTP / HTTPS pages, the extension reads page text to identify foreign-currency prices and inserts estimated conversions beside them. This can involve other text on the page, but processing stays on your device and the extension does not send that text to the publisher or exchange-rate provider. It does not build a full browsing-history log, read cookies, read passwords or payment details entered into form fields, or place orders or make payments.

Local storage

chrome.storage.local stores the target currency, interface language, global and per-site switches, fee percentage, manual rates, website currency overrides, and cached rate tables, source dates, update/retry timestamps and error state. Website settings are keyed by the domain present when you save settings. When you open the popup, activeTab allows the current tab URL to be read so its hostname can be extracted for site settings; full URLs and product lists are not stored. The extension does not sync this data to a developer server and does not use chrome.storage.sync.

Exchange-rate service and external connections

When a page or popup requests state, the extension may fetch a USD-based rate table over HTTPS from https://open.er-api.com/v6/latest/USD and calculate cross-rates locally. It normally reuses a cache for approximately 24 hours; manual refresh is available and failed automatic retries are throttled. In v3.0.4, reading settings is local only. Global or per-site disabling prevents that page from initiating new automatic rate requests. No automatic fetch is triggered for a page with no conversions needed or with valid manual rates for all detected source currencies. A mix containing other currencies without manual overrides may still fetch rates. Clicking Update rates in the popup is an explicit exception; requests already sent before disabling are not retroactively cancelled. In older versions 3.0.2/3.0.3, state requests may check rates even with manual rates or display disabled. These requests do not include products, prices, page text, browsing URLs, site preferences or account credentials. The provider and its network infrastructure can nevertheless receive IP addresses, request times and ordinary connection information. Their own policies govern that processing, and this extension does not control their logs or retention. Provider terms and privacy information: https://www.exchangerate-api.com/terms .

Sharing, advertising and tracking

The publisher operates no backend for collecting page content, usage logs or personal data. This version has no advertising SDK, analytics tracker, telemetry or extension account system. Page data is not sold, and local data is not used for advertising, creditworthiness or purposes unrelated to conversion. Clicking a rate attribution or other external link visits that website directly, under its policies.

Permissions

storage saves local preferences and rate caches. activeTab obtains the current site domain when you open settings. Access to HTTP / HTTPS page content identifies prices and displays estimates across websites; you can use the extension’s per-site switch or Chrome’s site-access controls to restrict this. Host access to open.er-api.com fetches exchange-rate JSON over HTTPS. Remote responses are used as data, not executed as remotely hosted code.

Retention, controls and deletion

Local settings and rate caches remain until updated, cleared or the extension is removed; there is no fixed automatic retention limit while installed. You can edit settings, clear individual manual rates, disable conversion on a site or uninstall. Uninstalling normally removes the extension’s Chrome-managed local storage; browser or system backups you create are managed separately. The publisher cannot remotely inspect or delete local settings or delete the rate provider’s connection logs on your behalf.

Limited use and policy changes

The extension’s use of user data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements, and is limited to providing and maintaining its disclosed price-conversion features. If data practices change, this policy will be updated with an effective date and material changes will be disclosed as required by applicable store policy.
